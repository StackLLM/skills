# Positionnement des Skills

Fondé sur les capacités vérifiées dans chaque dépôt (version 0.1.0). Aucune Skill ne remplace entièrement un expert : elles prennent en charge une méthode, et l'humain garde la décision.

## Message de gamme

Pas des prompts : des **outils d'automatisation et d'expertise technique**. Chaque Skill embarque une méthode fixe, des scripts quand c'est utile, et des contrôles avant livraison.

Ce qu'elles apportent, toutes ensemble :

- **Moins de temps** sur des tâches longues et répétitives.
- **Des workflows standardisés** : même méthode, même qualité, d'un projet à l'autre.
- **Des livrables vérifiés** : tests, mesures ou contrôles automatiques, pas seulement « ça a l'air bien ».
- **Aucune invention** : ce qui n'est pas lu ou mesuré est marqué comme tel.

## Par Skill

| Security Auditor | freelances, PME, startups | pas d'audit avant la prod | constats triés par criticité et confiance, avec correction | revue avant mise en production | B+ : scripts + exemple | ne remplace pas un pentest |
| Deployment Advisor | devs non spécialistes infra | pannes découvertes en production | pièges détectés tôt, architectures chiffrées, checklists | premier déploiement, migration | B+ : scripts + exemple | ne déploie rien ; coûts indicatifs |
| Docs Premium | freelances, agences, équipes produit | documentation tardive et hétérogène | livrables homogènes, fondés sur le vrai projet | fiche technique, guide, rapport client | B : méthode complète | captures réelles requises pour le guide |
| cv-ats | candidats, recruteurs, coachs | CV mal lus par les ATS | 3 PDF contrôlés, sans fait inventé | refonte de CV, accompagnement carrière | A : scripts + 6 tests | macOS uniquement |

Maturité : **A** = scripts et cas ou tests validés · **B** = méthode complète sans test automatique.

## Avant toute commercialisation

- Étude de marché et prix : non faite.
- Licence commerciale définitive : à rédiger et faire valider.
- Mode de distribution (dépôt privé partagé, archive, marketplace de plugins) : à choisir.
- Tests automatiques pour les Skills de maturité B.
- Page de présentation dans le portfolio et sur le profil StackLLM : seulement au lancement.
